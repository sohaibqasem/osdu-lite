# OSDU Oil & Gas Tutorial Sample Pack

This pack accompanies `OSDU_Oil_Gas_Client_Step_by_Step_Tutorial.docx`.

Files:
- wells.csv - fictional source Well data
- wellbores.csv - fictional source Wellbore data
- well_logs.csv - fictional log/LAS catalog
- sample_well_record.json - illustrative OSDU Well record
- sample_wellbore_record.json - illustrative OSDU Wellbore record
- sample_welllog_record.json - illustrative OSDU WellLog WPC
- manifest_example.json - illustrative Workflow/Manifest payload
- search_wells.json - sample Search request
- osdu_client.py - reusable Python REST client

Important:
Schema versions and deployment routes vary. Validate JSON against the client's deployed OSDU schemas and Swagger/OpenAPI before ingestion.
